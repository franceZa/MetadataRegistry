ขั้นตอนจุดตัดสินใจสำเร็จหยุดหรือแก้ไข

1. เริ่มจาก trigger

PR เข้า master ใช้ CI และ Security; push สาขาอื่นใช้ Security; push เข้า master จึงสร้าง GitHub Release

2. ตรวจ release

release_id ผูกกับ 12 ตัวแรกของ commit SHA หาก id เดิมมี package ต่างกัน workflow จะหยุด

3. เลือก delivery

อ่าน delivery_mode จาก config/env/dev.yaml ค่าปัจจุบันคือ u2m: ผู้ใช้ login แล้วให้สคริปต์ทำ CD-1 ถึง CD-8

อ้างอิงจาก ci.yml, security.yml, release.yml, deploy-dev.yml, deliver_release.sh และ next_steps.py
